# shellcraft-plugins

The official plugins for [shellcraft](https://github.com/cmdworks/shellcraft), the fast single-binary
shell customization tool, plus the documentation for writing your own and a list of community
plugins.

```bash
shellcraft search                  # what is available
shellcraft install docker themes   # install by name, no configuration
shellcraft update                  # keep them current
```

The official plugins also ship inside the shellcraft binary, so `install` works offline. This
repository is where they are developed and where newer versions appear between shellcraft releases.

## Official plugins

| Plugin | Kind | What it does |
| :--- | :--- | :--- |
| [`base`](plugins/base) | profile | Starter set: installs `git-aliases`, `docker`, `themes` and `cheats` |
| [`docker`](plugins/docker) | feature | Docker/Compose marker in the prompt with the active context; podman fallback; `d`, `dc`, `dps`, `dsh`, `dlogs` |
| [`git-aliases`](plugins/git-aliases) | feature | `gs`, `ga`, `gc`, `gp`, `gl`, `gd`, `gco` |
| [`themes`](themes/colors) | theme | `nord`, `dracula`, `gruvbox` for the prompt, fzf, bat and shell highlighting |
| [`passionp`](themes/passionp) | theme | icons, a red-yellow-green arrow, jobs and command time on the right (Nerd Font) |
| [`cheats`](plugins/cheats) | feature | Cheat sheets for git, tar and ssh (`shellcraft cheat <topic>`) |

Community plugins are listed in [`community/index.toml`](community/index.toml); see
[docs/community-plugins.md](docs/community-plugins.md). Add the list with
`shellcraft registry add cmdworks/shellcraft-plugins/community`.

## Write a plugin

1. [Getting started](docs/getting-started.md): a plugin in ten minutes.
2. [Plugin kinds](docs/plugin-kinds.md): a worked example of each (prompt segment, command, hook,
   shell snippet, theme, cheat sheet, prebuilt binary).
3. [Writing a theme](docs/themes.md): colours, the shape of the prompt, icons.
4. [Publishing](docs/publishing.md): versions, the index, signing.
   [Plugins with compiled code](docs/binary-plugins.md): prebuilt binaries and a release workflow.
   Where plugins can live (this repository, your own GitHub or git repository, a folder of a repository):
   [distribution rules](https://github.com/cmdworks/shellcraft/blob/main/docs/plugin-distribution.md).
5. [Review checklist](docs/review-checklist.md): what reviewers look at.

The manifest format and everything shellcraft promises to plugins is the **plugin API**, versioned
and documented in the main repository:
[docs/plugin-api.md](https://github.com/cmdworks/shellcraft/blob/main/docs/plugin-api.md).
Starting points to copy are in [`templates/`](templates).

## Layout

```text
plugins/<name>/   one folder per official plugin (shellcraft-plugin.toml and its files)
themes/<name>/    one folder per official theme (same format, kind = "theme")
index.toml        the registry index (generated by `shellcraft registry publish`; never edit by hand)
community/        plugins that live in other repositories, pinned by commit and hash
templates/        skeletons (what `shellcraft plugin new` creates)
docs/             guides
scripts/          check-all.sh, publish.sh
```
